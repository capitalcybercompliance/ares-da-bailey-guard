# Contributing to Marshall Bailey by Cyber Grants Alliance

Thanks for helping. Marshall Bailey is plain JavaScript, Manifest V3, with no build step.

1. Load the folder unpacked in Chrome (`chrome://extensions`, Developer mode, Load unpacked).
2. Make your change and reload the extension.
3. Test with the local pages in `test-pages/` only. Never visit a live phishing site and never type a real password into a test page.
4. Confirm the real Microsoft sign in page (`https://login.microsoftonline.com`) is never blocked.
5. Keep user facing text free of em dashes and en dashes.

Detection rule problems that also affect the upstream project belong with Check by CyberDrain: https://github.com/CyberDrain/Check
