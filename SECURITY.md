# Security Policy

If you find a security problem in Marshall Bailey by Cyber Grants Alliance, please report it privately through https://www.cybergrantsalliance.org/ instead of opening a public issue. Tell us what you found, how to reproduce it, and which version you used.

Problems in the shared detection rules or engine may also affect the upstream project, Check by CyberDrain (https://github.com/CyberDrain/Check). We pass those along.

Thank you for helping keep Marshall Bailey safe.
